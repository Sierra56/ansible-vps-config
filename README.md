Данный Ansible-проект предназначен для автоматической первичной настройки (bootstrap) и усиления защиты (hardening) Linux-серверов (VPS). 

Поддерживаются семейства ОС **RedHat** (Alma, Rocky, CentOS) и **Debian** (Debian, Ubuntu).

## ✨ Возможности

- **Bootstrap:** Автоматическая установка Python 3.8+ на "чистый" сервер для работы Ansible.
- **Пользователи:** Смена пароля root, создание привилегированного пользователя, добавление SSH-ключей.
- **Настройка ntp:** Смена часового пояса и настройка синхронизации с сервером pool.ntp.org
- **SSH Hardening:** Изменение порта SSH, отключение входа по паролю и запрет входа под root.
- **Fail2ban:** Установка и настройка fail2ban для защиты SSH от брутфорс-атак (с учетом кастомного порта и белого списка IP).
- **Firewall:** Настройка firewalld (RedHat) или ufw (Debian) и открытие необходимых портов.
- **Базовые пакеты:** Установка базовых утилит (htop, ncdu, curl, git и др.).
- **3x-ui Panel:** Автоматическая установка панели 3x-ui и вывод учетных данных для доступа.

## 📂 Структура проекта

```text
ansible-vps-setup/
├── ansible.cfg                 # Конфигурация Ansible
├── requirements.yml            # Список зависимостей
├── site.yml                    # Главный плейбук (точка входа)
├── inventory/
│   └── inventory.yml           # Инвентарь серверов (группы vps, test)
│
├── group_vars/
│   └── all/                    # Общие переменные для всех групп
│       ├── vars.yml.example    # Публичные настройки (порты, пользователи, пакеты)
│       └── vault.yml.example   # Зашифрованные секреты (пароли)
│
└── roles/
    ├── bootstrap/              # Установка Python через raw
    ├── common_packages/        # Установка базовых пакетов (dnf/apt)
    ├── users/                  # Настройка пользователей и SSH-ключей
    ├── ssh_hardening/          # Харденинг sshd_config
    ├── fail2ban/               # Настройка защиты от брутфорса
    ├── firewall/               # Настройка firewalld / ufw
    └── xui/                    # Установка панели 3x-ui
